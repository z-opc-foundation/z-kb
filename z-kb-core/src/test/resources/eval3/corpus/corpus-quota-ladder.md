# Zorp 配额阶梯与降级策略

> 归属系统：配额服务 qltd　　当前负责人：柯野　　文档版本：v5

## 适用范围

本手册描述 Zorp 配额阶梯与降级策略 的现行口径，与线上配置一致。若与代码默认值冲突，以配置中心为准。

## 核心参数

| 项目 | 取值 | 说明 |
| --- | --- | --- |
| 基础配额 | 每月 2,400 万次 | 超出部分按 1.6 元/万次计费 |
| 第一级降级触发 | 占用达 82% | 第二级为 91%，第三级为 97% |
| 第三级降级后响应 | 只读 | 写接口统一返回 ERR-5031 |
| 配额快照周期 | 每 53 秒 | 快照存于 qltd_snapshot 表 |
| 临时提额单号前缀 | TMP-Q | 单次提额上限为基线的 1.25 倍 |

## 补充说明

《Zorp 配额阶梯与降级策略》的补充说明

本策略旨在确保Zorp平台的资源分配公平合理，避免单一用户或服务过度占用资源，影响其他用户的正常使用。配额阶梯设计考虑了用户需求的多样性，通过分层管理，确保资源高效利用。日常使用中，用户应关注自身资源使用情况，合理规划，避免触及上限。当遇到资源不足或使用受限的情况时，建议首先检查个人配额使用情况，必要时可联系配额服务团队（负责人：柯野）进行咨询和调整。
