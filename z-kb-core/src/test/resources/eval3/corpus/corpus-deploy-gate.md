# Zorp 发布闸门规范

> 归属系统：流水线 gatek　　当前负责人：岑野　　文档版本：v3

## 适用范围

本手册描述 Zorp 发布闸门规范 的现行口径，与线上配置一致。若与代码默认值冲突，以配置中心为准。

## 核心参数

| 项目 | 取值 | 说明 |
| --- | --- | --- |
| 灰度首批比例 | 3% | 观察窗口为 23 分钟 |
| 回滚判定指标 | 错误率超过基线 1.8 倍 | 或 P99 上升超过 240ms |
| 强制人工确认环节 | 第 3 道闸 | 确认人须为非提交人 |
| 发布窗口 | 工作日 10 点至 16 点 | 周五不发布 |
| 闸门豁免单前缀 | EXEMPT-A | 豁免有效期 72 小时 |

## 补充说明

《Zorp 发布闸门规范》中的“补充说明”一节旨在解释为何将发布闸门的默认等待时间设定为当前标准，以及如何在日常工作中应用这一规范。岑野作为流水线 gatek 的负责人，根据过往的项目经验和团队反馈，确定了这一时间参数，以确保代码质量的同时，不阻碍开发进度。在日常操作中，团队成员应遵循此规范，确保每次提交代码后，等待闸门检查通过后再进行后续操作。若在使用过程中遇到问题，首先应检查闸门日志，查看是否有特定的错误信息或警告，以便快速定位并解决问题。
